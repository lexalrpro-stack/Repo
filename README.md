# Medieval Craft · мультиплеер на Render

В репозитории 3 файла: `index.html` (игра), `server.js`, `package.json`.

## Запуск (5 минут)
1. Создай репозиторий на GitHub и залей туда все файлы из этой папки.
2. render.com → **New → Web Service** → выбери репозиторий.
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Instance type: Free
3. Когда сервис запустится, открой его адрес `https://твой-сервис.onrender.com` — игра откроется сразу, и адрес сервера в окне «🌐 Мультиплеер» подставится сам.
4. Один игрок: **Мультиплеер → Создать комнату** (сид, плоский/холмы и креатив/выживание берутся из главного меню). Получит код из 4 символов.
5. Остальные: тот же адрес → **Войти в комнату** → код.

Играть можно и с локального файла: в поле «Адрес сервера» впиши `твой-сервис.onrender.com`.

## Как это работает
- Мир строится из одного сида у всех игроков, сервер хранит только сид и изменения блоков (поставил, сломал, двери, калитки).
- Игроки видны с именами, есть чат (💬 или клавиша T), время суток берётся у хоста.
- Комнаты живут 6 часов после выхода последнего игрока. Лимит — 8 игроков (`MAX_PLAYERS` в настройках Render).

## Ограничения
- Бесплатный Render засыпает через ~15 минут без трафика: первое подключение может идти до минуты. После перезапуска сервера комнаты на бесплатном диске пропадают.
- Мобы, сундуки и выпавшие предметы у каждого свои. Только новые миры: сохранённые миры из «Мои миры» на сервер не загрузить.
